# 宿主能力与交付

每次会话按实际可用工具核对 terminal、readWriteFiles、questionUI、localMediaPreview、fileLinks；未知视为 unavailable。品牌名不能证明当前会话有这些能力，跨设备也不继承上次的判断。

图片生成另外核对 imageGeneration、referenceImages、imageEditing 和 resultFileRecovery：实际工具名称与调用契约、参考图数量与类型、修改能力、是否能取得本次结果的可读文件。按 [图片来源规范](specs/IMAGES.md) 写本次能力描述；skill 与内置工具若指向同一生成器不重复列选项。Codex imagegen 是 Agent 工具路线，不能由 Python API fallback 冒充；其他宿主须实际发现可调用能力后才提供。工具能力文件是 Agent 的核实记录，引擎不能在 CLI 进程内自行探测宿主。

所有图片阶段每批生成前在 questionUI 选择来源；同批只确认一次。无窗口改文字，完全无人交互则必须显式提供本批 method、signature 与真实授权 source。推荐按项目记忆，绝不能自动批准。结果不能回收时等待手动导入，不标为完成也不自动改用 API。

有终端和文件权限时，从实际加载入口解析安装根，先检查环境再制作。没有终端或文件权限时，只准备当前能完成的简报/剧本，说明本地继续所需步骤；不得声称已安装依赖、已渲染或审片通过。

questionUI 可用时用其实际支持的卡片；否则使用同一问题的编号文字选项并等待明确回复。默认选项、超时、空回复不等于批准。已明确的素材来源、画幅、字幕和草稿交付不重复问；制作审片节点完整保留。

制作简报先给待确认整套建议，只补问关键缺项。每轮最多3个互不依赖问题、每题一个决定；依赖未定时先解决前置。用户要求逐题或宿主只支持单题时一次一问。整份简报仍需明确签批，默认推荐与异步工具返回不等于已回答。

视频每一批（含重试、返修、副版）提交前按 [视频批次规范](specs/VIDEO.md) 弹窗说明模型、数量、源片／成片时长、预计费用和预算，等待明确开始，再绑定计划signature；配置选择和“继续”不代替该授权。无窗口时文字提问并等待，不能静默提交。

长任务在宿主可恢复后台执行，单次等待不超过60秒；工作未结束时每60秒内说明实际阶段、已完成项和下一步。工具返回仍在运行就继续查询同一任务，收到有效回答后主动推进到下一个真实待决点，不要求重复“继续”。没有后台能力时用短轮询并保留已提交任务；未取得实际提交回执时不声称已提交。宿主图片中断先查已返回文件，只对确实没有可回收结果的剩余项重新请求本批授权。

原生入口继续用当前宿主已有命令；portable 使用自然语言“使用 wukong-drama 检查环境/列风格/开始制作/继续工程”，不猜测专有斜杠命令或工具。

媒体预览工具确实可用并成功打开后才能记为已预览。Codex/Claude 使用原有交付格式；其他宿主用 `delivery --host generic`，从清单取得真实绝对路径、资源类型和 previewStatus: unverified，再按该宿主实际文件链接、附件或预览机制交付。没有这些能力时交付可读的真实路径及未验证说明，不伪造 file://、下载链接或播放成功。云端路径必须在实际工作区/下载机制可访问，本地 home 不等于远程资源。

安装成功、宿主发现入口、环境检查、实际渲染、媒体打开分别记录。卡片或文件存在不构成客户签批；现有导演流程中的必要签批均等待用户明确回复。
