# 分镜表填写规范（storyboard.md）

> `storyboard.md` 供审阅，也提供实际生成提示词；`film.json` 管镜号、时长等工程信息，两者逐镜对应（`film.json` 各字段见 `FILM.md`）。

- **工序**：第 6 道 · 审片节点 ⑤ 分镜
- **模板**：`engine/templates/film/storyboard.md`，第 3 道 `wkd init` 建工程时带出空白稿 `films/<片名>/storyboard.md`
- **流程**：怎么提交、签批被拒怎么办见 `../SKILL.md` 第 6 道
- **示例**：各风格示范片保留制作当时的格式；新片按当前模板填写，不向历史签批材料补造三栏

## 一、表头

总长、画幅、分辨率与帧率、风格、种子、对应的剧本版本号。

## 二、逐镜各栏写法

栏目按观看顺序排：编号信息 → 怎么进这一镜 → 看到什么 → 听到什么。没有内容的栏写"—"。

| 栏目 | 写什么 |
|---|---|
| 镜 | 镜号 `s01`、`s02`……，与 `film.json` 的 `shots[].id`、`shots/sNN.json` 一一对应 |
| 段落 | 这一镜属于剧本的哪一段（起 / 承 / 转 / 合）。同一段可拆成多镜，各段镜头时长之和应与剧本的段落时间一致 |
| 时长 | 默认单镜 3–8 秒，动作完成后至少停 1 秒；风格另有规定的以风格为准。独立人声按实测时长核对 |
| 转场 | 进入这一镜的方式，只能用风格转场表里的名称，同步写入 film.json 的 shots[].transition；第一镜写"—"。硬切要少，`wkd qc` 会数 |
| 景别 | 大远景 / 远景 / 全景 / 中景 / 近景 / 特写 / 大特写，同时写进 `film.json` 的 `shots[].size`。规则见第三节 |
| 画面 | 简写观众看到什么，不重复详细提示词，不写代码 |
| 运镜 / 动态 | 简写动作、运镜和节奏；细节放过渡提示词 |
| 首帧提示词 | 动作开始前的主体、道具状态、位置、景别、构图、环境和风格；第 7 道据此生图 |
| 过渡提示词 | 本镜内从初态到终态的动作顺序、运镜和节奏，不是镜间转场 |
| 尾帧提示词 | 动作完成后的状态、位置、构图和停留；第 8 道作为文字结束目标，不额外生成尾帧图 |
| 屏幕文字 | 剧本「屏幕文字」里的哪一条在这一镜出现、以什么形式出现；剧本里的每一条都要落到某一镜 |
| 人声 | 这一镜的人声文案原文，一字不改。默认画外音（VO，内心独白也算），直接写引号原文；其他类型加标记：`对白（角色）：`出镜说话、`OS（来源）：`画外但在场景里、`同期：`现场原声或采访 |
| 音效 | 只写落在这一镜里的点状音效：同步点名（对应 `film.json` 的 `cues`）、入点时刻（全片时间）、音效类型，如 `亭现 6.2s 轻钟` |

## 三、景别规则

景别决定画面的视觉节奏，`wkd signoff --step 6` 会查。

- 按主体占画面的比例判断，不按镜头叫什么：同一幅长卷横移，比例没变就是同一种景别。
- 4 镜及以上，全片至少用 3 种景别。
- 相邻两镜景别不同；同一幅画「连续」转场的两镜除外，但全片仍要满足至少 3 种。
- 表下附一行景别序列，如「远景 → 全景 → 特写」。

## 四、声音铺底

BGM 和环境声通常跨好几镜，不进逐镜表，在表下「声音铺底」按全片时间轴单列。每行写时间段、类别（BGM / 环境声）、内容或情绪、淡入淡出与静音等动作，连续配乐优先统一后期铺，视频提示词要求无背景音乐、保留对白和环境／动作声；仍可选全原生方案并审听切镜接续。独立声音用 audio.tracks 或按需 audio/build.mjs 接入。

## 五、取决于风格的栏，查 STYLE.md

这里只定栏目和通用规则，不写任何风格自己的取值。各风格 `STYLE.md` 的一级章节固定，查哪一节都一样：

| 分镜栏 | 查 STYLE.md 哪一节 | 查什么 |
|---|---|---|
| 时长 | 6. 运动语言 · 时长 | 本风格的单镜时长、动作后停多久 |
| 转场 | 6. 运动语言 · 转场 | 可用的转场名称、何时用、硬切限额 |
| 景别 | 4. 构图 · 景别对照表 | 各景别在本风格里画成什么样 |
| 画面 | 4. 构图 | 主体位置、分层、留白、安全区 |
| 运镜 / 动态 | 6. 运动语言 | 怎么动、缓动、速度上限 |
| 屏幕文字 | 3. 文字 | 字体、字号层级、出现形式 |
| 音效、声音铺底 | 7. 声音 | 音效清单与密度、配乐 / 环境声 |

三栏是生成依据，按 STYLE.md 写可见效果和运动，不写代码或内部积木名。画面、运镜概述与三栏有冲突时，先改分镜再生成；实际视觉语义仍需人审。

## 六、副版重排

有副版（`film.json` 的 `variants`）的片子，第 13 道「改版」开工时在 `storyboard.md` 末尾加这张表，每镜一行。不改上面的逐镜表：镜头、时长、声音两版共用。

```markdown
## 副版重排（9:16）

| 镜 | 处理方式 | 怎么排 | 首帧提示词 | 尾帧提示词 |
|---|---|---|---|---|
| s01 | 导入裁切素材 | 人物居中，底部留字幕区 | 人物站在庭院中央，尚未伸手，竖屏全身 | 人物伸手接住落叶，保持竖屏全身 |
| s02 | 独立生成副版 | 两人改为前后站位 | 两人前后站立，前者尚未转身，竖屏中景 | 前者转身望向后者，站位不变 |
```

- 原图/原视频不覆盖，副版素材与模型任务按画幅分别保存。
- JSON 覆盖文件可以指向已核对的本地裁切素材，也可按副版表的首尾提示词生成；不能假定模型自动执行版式规则。
- 「怎么排」写具体变化，依据 STYLE.md 的画幅重排规则；镜号、时长、声音和剧情与主版共用。

副版只重排首尾构图，动作、结束事件和声音沿用主版；新生成前须填该画幅的首尾栏。不得借改构图改剧情。副版首帧及尾态构图文字在新视频生成前按第 7 道集中确认；尾态构图变化只补审该项文字，未变的首帧图沿用。

## 七、实际生成与修改

- 三栏每镜必填；静止镜头写清保持状态。单元格用 `<br>` 换行，字面竖线写 `\|`，不要把同一镜拆成多行。时长写 `2s` 或 `2秒`，与 film.json 一致。
- 图片指令自动取首帧栏；视频自动组合三栏、计划镜长、人声原文、音效与声音铺底，再带入已确认设定。统一后期配乐时，在 BGM 的动作栏写“统一后期”，模型指令会要求无背景音乐；全原生方案照常写音乐要求。声音铺底的时间用 `0–10s`，无明确范围则全片沿用；实际指令只带入与本镜相交的范围，音效时点自动换成镜内时间。
- 三栏描述最终剪入成片的镜头；源片更长时，要求在计划镜长内完成动作，余下保持结束状态。实际切入、切出状态须看片核对，文字目标不保证精确执行。先尝试调整 source_start 选段，确需重生另行确认。
- 镜头 JSON 不另写一套完整提示词。可省略三个同名英文字段；如填写，必须与分镜一致，详见 `SHOT.md`。生成计划展示实际拼合指令，费用授权仍需单独确认。
- 改分镜只重审受影响镜；首帧图及其初态未变时，单改过渡、尾态或声音不要求重新审图。改剧本、首帧或实际图片则重审相应内容。旧素材和已提交任务可复用；旧表仅在新生成前补齐，不补写历史批准。

首帧图必须对应初态。签批前 content-review --step 6，批准时带同批 content-signature；部分返修使用相同 --only，只重审受影响行。
