# 开拍或继续一支模型短剧

先读取同一插件内的 `../director/SKILL.md`，按其中的 16 道工序和 13 个审片节点制作。支持三种创作入口：一句话创意、已有剧本、已有分镜/素材。先读取用户已提供内容和系列项目的确认版设定，不重复索取。没有故事或主题时才询问，不猜测用户已经签批。默认新剧集为 9:16、每集 30–90 秒，具体项目要求优先。

## 定位引擎与工程

本文件位于 `<插件根目录>/skills/film/SKILL.md`。先取得**当前加载的本文件所在目录的真实路径**，再上移两级目录，得到插件根目录；引擎是其中的 `engine/bin/wkd.mjs`。不要依赖宿主的插件路径环境变量，不要写死源码仓库路径或缓存版本。

确认当前工作目录是用户要存放作品的目录。如果当前目录位于插件安装目录或缓存内，先让用户指定工程目录；没有本地终端或文件访问能力时，说明需要切换到桌面本地执行环境。

在用户工程目录下依次运行（把示例中的 `<插件根目录>` 替换成上面解析出的绝对路径，路径保留引号）：

```bash
node "<插件根目录>/engine/bin/wkd.mjs" check
```

`check` 不验证 API 账号或额度；生成前还须准备当前批次计划与授权。`check` 返回非零时停止开拍，引导用户运行本插件的 `setup` skill（可以说「用 wukong-drama 检查并配置环境」）；不要继续初始化或渲染。通过后再运行：

```bash
node "<插件根目录>/engine/bin/wkd.mjs" init-project
node "<插件根目录>/engine/bin/wkd.mjs" status
```

如果有在制的片子，先询问用户恢复哪支或新建。选择卡片使用宿主实际提供的提问工具；不可用时用编号选项提问，等待明确回复。制作简报、画风和每个审片节点的签批仍按 director 执行，不能把开拍请求当成后续节点的批准。

制作简报先基于已有信息提交待确认整套建议，只有关键缺项才提问；每轮最多3个独立问题、每题一个决定，依赖问题等待前置回答。用户要求逐题或宿主只支持单题时一次一问。收到有效回答后主动继续，保留全部必要审片节点与每批模型生成授权。
