# 新建模型短剧风格

用户风格存入 `~/.wukong-drama/styles/<id>/`，升级不会覆盖；`wkd list styles` 标为 `[用户]`。流程和审片仍读 `../director/SKILL.md`。

1. 确认风格特征、适合的故事、色彩、构图、运动和声音；已有明确要求直接采用。
2. `wkd new style <id> --name <名称>` 建目录。新片统一使用 `generation`，不为新风格编写画面 JS/React。
3. 完善 `STYLE.md` 固定十节：本质、色彩、文字、构图、技法、运动语言、声音、禁忌、示范片、质检。保留可观察的视觉标准。
4. `TECH.md` 写图片提示词模板、视频动作模板、参考图使用方式、角色一致性与副版重排策略。镜头格式见 `../director/specs/SHOT.md`。
5. `style.json` 声明 `pipeline: "generation"`，保留画幅、字幕字体与样式、音效和 QC 配置；不要把 API 密钥或账号权限写入风格。
6. 做一支 10–15 秒模型示范片，按 16 工序和 13 审片节点执行；无副版时跳过改版节点。保存源素材和任务记录，实际完成后才写入示范片列表。
7. `wkd list styles` 核对配置；对实际生成的片子运行 QC，并人工检查角色、道具、画面文字、动作和声音。自动 QC 通过不等于模型画面无瑕疵。

风格目录由 `SKILL.md`、`STYLE.md`、`TECH.md`、`style.json` 与可选的参考素材组成。不得将尚未生成的分镜标为模型示范成片。
