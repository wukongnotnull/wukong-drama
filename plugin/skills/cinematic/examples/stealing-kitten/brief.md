# 《偷蛋的小猫》制作简报

## 一、目的与受众

- **用途**：抖音娱乐短视频（根据已选平台与轻喜剧基调推断）。
- **投放平台**：抖音；同时交付横屏版。
- **目标受众**：喜欢萌宠和搞笑反转的大众观众。
- **看完后希望观众**：被小猫从偷蛋贼变成临时保姆的反差逗笑（根据已确认故事与基调推断）。

## 二、内容

- **故事 / 主题**：小猫偷到一枚鸟蛋，小鸟随即破壳而出，把小猫当成妈妈追着跑，小猫意外成为手忙脚乱的临时保姆。10 秒内突出“偷到蛋 → 破壳认妈 → 追猫收尾”，压缩铺垫。
- **一句话核心信息**：偷蛋的小猫，反而成了小鸟的妈妈。
- **基调关键词**：轻喜剧、俏皮、意外反转。
- **必须出现的元素**：小猫、鸟蛋、小鸟；无额外文字、标志或其他指定元素。
- **禁忌**：用户没有额外禁忌。
- **参考片 / 参考图**：无，从零制作。

## 三、制作规格

| 项 | 规格 |
|---|---|
| 片长 | 10 秒；竖屏与横屏版一致 |
| 画幅 | 9:16 竖屏主版 + 16:9 横屏副版，共用故事、镜头时长和声轨 |
| 人声 | 不用人声，无对白、旁白；猫叫、鸟鸣作为音效 |
| 配乐 | 轻快俏皮，在小鸟破壳时短暂停顿，突出笑点；配合动作与环境音效 |
| 字幕方式 | 不出人声字幕（按已确认的无人声方案推断） |

## 四、交付

- **交付形式**：9:16 竖屏与 16:9 横屏成片 MP4，两种画幅各一份剪映草稿。
- **期望交付时间**：未指定具体期限。
