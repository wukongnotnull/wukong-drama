# 真人影视 · 美术规格

## 1. 风格本质

以人物表演和场景真实感讲故事；肤质、光影、材质有可信细节，避免塑料皮肤和失真的肢体。

适合：自然人物、真实场景、镜头语言与角色连续性，适合生活、悬疑和剧情短剧。具体项目的美术方向以简报与参考图审阅为准。

## 2. 色彩

每场戏固定光源方向、色温与曝光关系；跨镜保留服装、场景陈设和时间段。色彩服务情绪，不突然改变肤色。

## 3. 文字

模型画面中的标题、招牌和数字逐字核对。精确文案优先使用已核对本地图像或引擎字幕；不让模型自动增加标志或无意义文字。字幕字体与样式按 style.json，底部保留安全区。

## 4. 构图

主体与环境至少形成两个层次，景别服务剧情。角色视线、动作方向与关键道具位置跨镜连贯。远景交代环境，全景看完整动作，中景承接互动，近景/特写揭示反应和线索。

### 画幅重排规则

横转竖：9:16 以人物纵向关系和动作区域为中心，缩减横向空景并保留完整动作。竖转横：16:9 补充横向环境与互动距离，保持人物比例和视线关系。副版使用独立 JSON 覆盖和素材；共用镜号、时长与声轨，保持主版源素材不变。

## 5. 技法

角色参考：复用同一组已批准的定妆图与明确版本；场景参考：固定布局、道具和光线。视频提示词只写可观察的动作、运镜和结束状态，避免同时要求过多动作。技术细节见 TECH.md。

## 6. 运动语言

以克制表演和清楚运镜为主；一镜一种主要运镜，人物走位遵守空间关系与视线方向，避免无因的镜头漂移。

默认单镜 3–8 秒；故事要求长镜时以实际模型能力和用户批准规格为准，不承诺一条提示词能完整执行复杂动作。连续、硬切、淡入淡出按分镜明确记录；自动 QC 与人工检查共同确认切点和接缝。

## 7. 声音

默认独立人声、配乐、环境声与音效，沿用导演第 7/8 道的试听、分轨、闪避与响度处理。用户选择原生声音时先确认方向，视频产出后实际审听音乐与动作音效；没有对白不代表无声。不承诺精准口型。

## 8. 禁忌清单

- 不改变已批准角色的身份、衣着、关键道具或场景关系而不记录新版本。
- 不将人物/肢体变形、文字漂移或漏动作当作技术 QC 通过后的可忽略问题。
- 不承诺固定 seed 保证复现，不自动付费重试或切换模型供应商。
- 不覆盖原素材、旧版本或确认版连续性。

## 9. 示范片

[《偷蛋的小猫》](examples/stealing-kitten/README.md)：已实际生成并完成用户验收的10秒真实萌宠轻喜剧，9:16与16:9双版、六镜、24fps，每镜不超过2秒。原生生成素材720p，最终编码为1080p尺寸；图片来自Codex内置imagegen，视频来自Seedance 2.5，声音为原创合成与拟声。示例包含实际媒体、提示词、设定与可离线重渲染工程。

`examples/demo` 仅提供生成前的 JSON 工程和镜头；文稿使用引擎统一模板。新项目不得沿用示范片授权，媒体使用说明见示例目录。

## 10. 交付前质检

- [ ] 角色脸、身形、衣着、道具与已批准参考一致。
- [ ] 主要动作完整，因果清楚，镜间方向连续，结尾停留足够。
- [ ] 字幕安全区与画面文字经过实际检查。
- [ ] 实际视频时长、尺寸、帧率、音轨符合当前计划；预算与任务记录可追溯。
- [ ] 源素材已保存，小样与高清复用同一版，未经批准的返修未进入正式设定。
