# 动漫短剧：图片与视频提示词

镜头格式见 `../director/specs/SHOT.md`。图片按本批选择使用助手工具或已配置的 API；视频及 API 型号由环境或 film.generation 配置，不在风格中固定。

## 图片

按“画幅和景别 → 人物及参考版本 → 表情/姿势 → 场景布局 → 光线色彩 → 留白与禁止变化”编排。例：

> 16:9 中景，一名戴蓝色围巾的角色站在公园小径旁，微笑望向手中的纸风车；树木位于背景，柔和晨光，清晰轮廓与简洁色块。保留参考图中的面部和服装特征，画面底部留字幕安全区，不添加无关人物或文字。

角色定妆图和场景图写进 references；已有合适图像可用 image 导入。连续场景检查人物与道具相对位置。参考图先交用户审阅，批准后才能进入视频批次。

## 视频

只安排一个主要动作链，写清开始、动作因果、结束姿势、镜头运动与声音方向。强调角色身份、衣着、背景和道具稳定，复杂剧情以模型已验证能力与当前批次计划为边界。

二维卡通可要求弹性形变并恢复原形；真人影视则要求自然动作和可信肢体。实际生成后逐项看动作完成情况，不用 prompt 代替画面证据。

## 计划、复用与改版

图片先 image-plan，选择来源后 image-approve；视频先 generation-plan --kind video，展示当前批次后弹窗等待明确开始，再 generation-approve --kind video --signature <计划签名>。未核实价格/规格或参考图未通过时不提交视频。轮询/下载/转码继续原任务，失败不自动重发；新 revision 也不能绕过累计上限。

原图与原视频保存在 assets/generated。副版写 shots/sNN.9x16.json 等覆盖文件，重排构图或导入已核对裁切素材；镜号、时长与声轨共用，主版不覆盖。批次批准、剧情确认、技术 QC 与视觉审片分别记录。
