# 浏览与推荐短剧视觉风格

本文件位于 `<插件根目录>/skills/styles/SKILL.md`。先取得**当前加载的本文件所在目录的真实路径**，再上移两级目录得到插件根目录，不依赖宿主的插件路径变量或固定缓存版本。

1. 读取同包的 `<插件根目录>/catalog.json`。
2. 在有本地终端与 Node.js 20+ 的环境中运行（替换实际绝对路径，保留引号）：

   ```bash
   node "<插件根目录>/engine/bin/wkd.mjs" list styles
   ```

   CLI 会补充用户自定义风格及配置检查结果；不可执行时仍可展示 catalog 中的内置风格，但明确说明尚未检查本机环境与用户风格。
3. 用表格展示序号、名称、分类、适合拍什么、是否可用。只展示实际提供的风格，区分配置正常与不可用；配置正常也不代表本机依赖、模型权限和额度已验证。内置真人影视、动漫、水墨均使用模型生成。
4. 用户给了关键词时，结合 `keywords`、`best_for` 与 CLI 检查结果，优先推荐配置正常的风格，最多 3 种；不足 3 种就如实说明，不虚构尚未提供的风格。

本技能只读：不要运行 setup、init-project、brief、init 或 render，也不要自动切换到 film。最后说明用户可以说「用 wukong-drama 按这个风格拍一支短片」开拍，等用户提出制作请求后再进入导演流程。
