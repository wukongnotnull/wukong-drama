# 水墨写意：模型制作说明

图片使用本批选择的助手工具或 API，视频使用已配置模型；镜头是 `shots/sNN.json`，字段见 `../director/specs/SHOT.md`。`STYLE.md` 的色彩、留白、构图和声音规则仍是验收依据。

## 图片提示词

按“画幅 → 景别 → 主体与位置 → 陪衬和层次 → 纸色与墨色 → 题字区域 → 禁忌”组织。例：

> 横屏 16:9，远景，右下方一叶小舟，左侧近山和远山形成两层，暖白宣纸肌理，清墨托出水面，右上留出题字区域；仅墨黑、纸白和极少朱砂，不使用油画厚涂、蓝天或金色光晕。

把同一角色、船只和关键环境的已批准参考图写入 `references`。提示词描述可见特征，跨镜保持服装、年龄、发型、船形和季节一致；不要用模型名或 seed 代替角色设定。

## 视频提示词

一镜只安排主要动作和一种运镜，写明开始、过程、结束与停留。例：

> 固定机位，小舟从右下缓缓驶向画面中心，远山不动，薄雾缓慢流动，水面涟漪细微；船体形状与人物衣着保持一致，结尾留出安静停顿，不切镜，不添加文字。

连续镜头以相邻镜的已核对静帧作为参考，逐帧检查接缝；提示词不能保证像素级连贯。墨晕和雾遮优先使用实际生成素材可实现的过渡，不伪称声画精确同步。

## 改版与返修

副版写 `shots/sNN.9x16.json` 等覆盖文件，按 `STYLE.md` 重新安排主体、留白和字幕安全区；共用镜号、时长、声轨。可导入已裁切且核对过的本地副版图和视频，或独立生成副版。主版源素材不覆盖。

修改提示词、参考图或模型会改变生成签名；需要相同条件再生成时更改 `revision`。轮询超时先续查原任务。保留 `assets/generated/` 中源图片、源视频及任务记录；小样/高清只做后期转码。

## 检查

人工看角色与物体稳定性、墨色是否越界、纸面纹理是否闪动、题字是否正确、镜间连续性。自动 QC 的留白、朱砂、黑帧和切点测量只覆盖技术指标，不证明人物或书法正确。
