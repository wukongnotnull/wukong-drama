# 水墨写意 · Chinese Ink Wash

> 墨分五色，计白当黑。画面靠"留白"呼吸，靠"笔势"运动。

适合：诗意短片、品牌片头、人文叙事、节气 / 节日、慢节奏画外音
不适合：快节奏广告、数据密集讲解、搞笑段子
画幅：16:9、9:16 · 时长：15–60s

## 1. 风格本质（先读这一段）

- **意在笔先**：先想清楚这一镜要表达什么情绪，再动笔。宁可少画，不可多画。
- **计白当黑**：留白本身就是画面的一部分，**每一帧留白 ≥ 40%**（`wkd qc` 会量）。40% 是下限，不是越多越好：「少画」是每一笔都有用，不是画面空。每帧仍要有前后层次（近处的枝、芦苇，中间的主体，远处的山、雾），主体之外有陪衬。
- **以线立骨，以墨造韵**：轮廓靠有粗细变化的笔线，体积和氛围靠墨色深浅与晕染。
- **动即是"写"**：画面中的运动，本质上是笔在纸上行走、墨在纸上晕开，而不是物体被"移动"。

## 2. 色彩

只用墨色和纸色，加一点点朱砂。图片提示词明确写出这些色彩，生成后核对。

| 名称 | 用途 | 值 | palette |
|---|---|---|---|
| 宣纸 | 背景底色（**绝不用纯白**） | `#F2EDE3` | `paper` |
| 焦墨 | 最重的点睛、舟身、题字 | `#141414` | `jiao` |
| 浓墨 | 主体轮廓 | `#2B2B2B` | `nong` |
| 重墨 | 次要结构、近山 | `#4D4D4D` | `zhong` |
| 淡墨 | 中景山、水纹 | `#8C8A86` | `dan` |
| 清墨 | 远山、雾 | `#C9C4BA` | `qing` |
| 朱砂 | 只用于印章 / 一处点睛 | `#B22C22` | `zhusha` |

- 朱砂面积 **≤ 画面 3%**，全片最多 **2 处**。
- 不使用任何其他颜色、阴影、发光、渐变色块。
- 墨色应呈现渗入纸纤维的质感，避免像不透明油漆贴在表面。

## 3. 文字

- 屏幕文字用两种形式：**题字**（竖排、右起，逐字自上而下写出）和**印章**（朱砂白文方印）。
- 题字放在留白处（如《春江花月夜》s19 的右上），印章随题字落下；朱砂的用量限额见「2. 色彩」。
- 题字和人声说的是同一句时，逐字跟着人声写出（见 director/specs/SHOT.md「屏幕文字与人声对位」）。
- 画法见技法「题字」「印章」。

## 4. 构图

- **三远法**：高远（仰望山峰）、深远（层层山谷）、平远（江面远眺），每一镜选一种。
- **散点透视**：横向镜头像展开"长卷"，不做 3D 透视推拉。
- 主体放在 **黄金分割点或画面一角**，不居中。
- 远中近三层：近景重墨、中景淡墨、远景清墨，越远越淡、越虚；山脚入雾。
- 9:16 竖屏改用"立轴"构图：上留天、下留地，主体在中下部。

### 画幅重排规则

第 15 道「改版」共用镜号、时长与声轨；副版使用 `shots/sNN.9x16.json` 等覆盖文件重新安排构图。画幅变化时保持主体比例、笔触粗细和字幕安全区，使用独立副版素材，主版不覆盖。

- **横转竖**：长卷改立轴。
  - 上留天、下留地，主体（舟、亭、月）移到中下部的黄金分割点。
  - 平远的横向铺展改成高远、深远的纵向层次：远山叠在上方，江面、近景放在下方，层与层之间用雾隔开。
  - 横向漂移的运动（舟行、雾散）改成短距离，或改成上下方向，不让主体一出发就出画。
  - 竖排题字放到上方留白处，印章跟着题字走。
- **竖转横**：立轴展成长卷。
  - 主体从中下部移到左右三分之一处，另一侧补远山或江面留白，不把竖构图原样居中、两边空着。
  - 纵向叠的层次横向错开：远山拉成一条横向的山脉，近景放到一角。
  - 题字放在留白最大的一侧，竖排不变。

### 景别对照表

水墨不做 3D 推拉，景别靠**画面里主体画多大**来定：换景别就是换一幅画（或在同一幅画上把主体画大），中间用墨晕 / 雾遮转场接上。

| 景别 | 本风格里的样子 | 怎么做到 |
|---|---|---|
| 远景 | 平远 / 深远的山水全貌，山只占画面一条，大半是江面、天空留白 | 「山石」`amp` 小、远山用清墨；主体（舟、亭、月）只是一个墨点（《春江花月夜》s06、s17） |
| 全景 | 主体完整入画并带着周围环境，如整叶小舟连同一片江面、整座小亭连同山腰 | 主体长边约占画面对应边的 1/4–1/3 |
| 中景 | 主体占画面一半左右，环境只剩局部，如舟与渔翁、半座山 | 主体长边约占画面对应边的一半以上（横长的舟按画宽算），远山退成清墨一抹或省去（《春江花月夜》s11：扁舟约占画宽一半） |
| 近景 | 主体的一部分撑起画面，如舟头与钓竿、题字连同印章 | 主体放大到出画，留白靠纸面而不是远景 |
| 特写 | 一个细节：一滴墨晕开、一方印、一笔飞白 | 只画一个元素，四周全部留白 |

## 5. 技法（提示词与参考图见 TECH.md）

镜头提示词按以下技法名称说明目标画面，实际生成后按视觉特征核对。

### 宣纸
低频斑驳（约 ±2%）、纤维和细颗粒。纸面纹理保持稳定，不能在每帧随机跳动。

### 笔触
- 起笔由细到粗，行笔宽度轻微变化，收笔收细。
- 飞白沿笔势留下长白缝，体现笔毛含墨量逐渐减少。
- 洇边是笔画外侧极淡的一圈晕，不是硬描边。
- 需要书写动作时呈现从起笔到收笔的连续过程；文字正确性另行核对。

### 墨滴
边缘不规则、中心浓而边缘淡，带颗粒和深色水线；晕开的半径先快后慢，最后停住。

### 山石
- 山脊有不对称主峰与自然起伏，两端收到地面。
- 山体淡墨从峰顶向下渐淡入雾；山脊用断续干笔勾勒。
- 皴擦沿山体向内短促斜向，从山脊向山脚递减。

### 雾
宣纸色柔和雾带，每秒漂移目标不超过 1% 画宽；实际视频中核对速度和连续性。

### 水
只显现几笔横向淡墨，其余全部留白，水面由留白表现。

### 小舟
一叶小舟连同渔翁，细节克制，船形与人物在动作中保持稳定。

### 题字
竖排、右起，自上而下。需要逐字书写时以每字 0.3–0.5 秒为节奏目标，模型文字必须逐字核对，不能保证精准字形和时间。

### 印章
朱砂白文方印，边缘斑驳；从约 1.08 倍缩到原尺寸、由透明到实，用时目标约 0.25 秒，不回弹。

## 6. 运动语言

| 要 | 不要 |
|---|---|
| 慢、匀、有呼吸感 | 快切、频闪、抖动 |
| `sineInOut` / `cubicOut` | 弹簧回弹、overshoot |
| 镜头横移如展开长卷（每秒 ≤ 4% 画宽） | 3D 推拉、旋转镜头 |
| 墨晕开、笔写出、雾散去 | 物体平移飞入、缩放弹出 |

### 时长

一镜 3–8 秒，一个动作完成后**停留至少 1 秒**再进入下一个（"留白"在时间上也成立）。

### 转场

| 名称 | 何时用 | 实现 |
|---|---|---|
| 连续 | 前后两镜是同一幅画的不同阶段（最常用） | 前镜末帧作为后镜参考，实际核对接缝构图与主体；模型不能保证两帧完全相同 |
| 墨晕 | 换一幅画、换景别 | 前镜末尾用「墨滴」晕开盖住画面，后镜开头从同一块墨淡开 |
| 雾遮 | 换一幅画，情绪更轻、更慢 | 前镜末尾「雾」漫过画面、最后整片铺成纸面，后镜从纸面开始雾散去；接缝两边都是纯纸面，不算硬切（需要在实际生成片中核对接缝） |
| 硬切 | 尽量不用 | 直接切 |

硬切全片 ≤ 2 次（`wkd qc` 会数）。

## 7. 声音

- 首选古琴式拨弦（`synth.qin`）、流水（`synth.water`），或几乎无声。
- 五声音阶（如 D 商调：D E G A C），音要稀疏，允许 2–3 秒完全静默。
- 人声语速放慢，句与句之间停顿 ≥ 0.8s。

音效（分镜「音效」栏）：

| 音效 | 场合 | 实现 |
|---|---|---|
| 笃 | 印章落下，与画面共用同一个声音同步点 | `synth.knock` |

音效和配乐一样要稀疏。

声音铺底：环境声用流水（`synth.water`，gain ≈ 0.1）整片铺底；配乐就是稀疏的古琴单音，不做连续旋律。

## 8. 禁忌清单

- 不要纯白背景，不要纯黑背景。
- 不要铺满画面，不要每个角落都有东西。
- 不要矢量感很强的均匀描边（像图标、像 PPT）。
- 不要阴影、发光、霓虹、渐变色块。
- 不要出现除朱砂以外的颜色。
- 不要模仿特定画家或特定作品的具体画面，用通用技法表达。

## 10. 交付前质检

- [ ] 每一帧留白 ≥ 40%（`wkd qc`）
- [ ] 至少能看出三种墨色层次（浓 / 淡 / 清）
- [ ] 笔线有粗细变化，有起笔和收笔，干处有飞白
- [ ] 墨滴晕染边缘带"水线"
- [ ] 朱砂 ≤ 2 处、面积 ≤ 3%（`wkd qc`）
- [ ] 没有弹跳、没有 3D 旋转、硬切 ≤ 2 次（`wkd qc`）
- [ ] 同一批准版本复用已保存源素材，人物/道具跨镜一致，无错误重生成
- [ ] 截任意一帧当静态画来看，也成立
