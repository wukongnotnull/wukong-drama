# 水墨写意

流程按 `../director/SKILL.md` 的 16 工序和 13 审片节点执行。先读 `STYLE.md` 的美术规则，再读 `TECH.md` 的模型提示词和参考图规范。

新片使用 generation 管线与 `shots/sNN.json`，图片负责构图和风格，视频负责受控动作。保留宣纸暖白底、墨色层次、朱砂限量、留白、节奏和声音要求。题字必须逐字审阅；精确文字使用已核对本地素材或后期字幕，不能假定模型能正确书写。

角色、船只、山形和季节跨镜保持一致，使用共同参考图和稳定描述。墨晕、雾与水波不应造成主体变形。生成原片必须保存，不能靠相同 seed 重建已签批画面。

`examples/` 内继承的代码示例仅说明美术与分镜结构，不是模型管线成片。
