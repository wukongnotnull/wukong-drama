# 模型生成管线

新剧使用 JSON 镜头，先生成或导入分镜图，再批准视频批次。`check()` 仅检查本地后期工具，不代表 API 账号可用。

`renderShots()` 通过 `generation/generation.mjs` 恢复原任务、复用持久素材，再按目标尺寸/帧率/帧数转码。源视频不足时失败，不复制最后一帧填补缺失动作。

远程生成源额外检查实际分辨率是否达到请求的原生规格，并在源视频旁保存 `.technical.json`，记录尺寸、时长、帧率及音轨。低清源不会放大冒充原生规格。本地导入允许按剪辑尺寸缩放，输出尺寸不代表导入源的原生清晰度。

`renderStills()` 优先从已有视频提取真实画面；视频尚未生成时使用分镜图。所有付费生成均须有匹配当前输入的批次授权、已核实估算及任务数量上限。

`assets/generated/` 保留原始素材和任务状态。启用 `generation.video.generate_audio` 时，原生音轨另存完整 WAV，供后期按镜头摆放和裁切。`.cache` 清理不删除这些源素材。
