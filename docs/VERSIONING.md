# 版本怎么递增

插件与引擎使用同一个版本号，从 **0.1.0** 起算。已发布版本和安装包见 [GitHub Release](https://github.com/wukongnotnull/wukong-drama/releases)。

| 改了什么 | 下一个版本示例 |
| --- | --- |
| 修问题、改文案，现有用法不变 | 0.1.1 |
| 增加功能 | 0.2.0 |
| 0.x 阶段改变旧用法 | 0.2.0，并提供迁移说明 |
| 功能和接口稳定，准备长期兼容 | 1.0.0 |

每次从当前版本递增，不重复使用已发布的编号。开发验证包沿用当前版本并标记 development，不当作正式包分发。

升版以 `plugin/plugin.json` 为准，同步宿主清单、marketplace、引擎和锁文件，再运行 `node tools/build-agent-docs.mjs`。画风的最低引擎版本按实际需要维护，不必随每次修复升高。

旧安装版本高于新包时，先备份作品、按原方式卸载，再安装；不要绕过降级或同版本覆盖检查。

发布前运行 `npm test`、`npm run lint`，从干净提交构建并核对两种包的版本和来源。只有实际发布时才创建对应的 `v版本号` 标签。
