# 第二步：准备账号和模型

先[装好插件](agent-installation.md)，再决定图片、视频分别怎么生成。**配置完成不会自动开始生成。**

## 需要准备什么

| 方式 | 准备什么 |
| --- | --- |
| 助手自带的图片工具 | 让助手确认当前能用、能满足本片要求；费用和额度由所在平台管理。 |
| 自己的图片或视频服务 | 已开通的账号、可用模型、足够额度和程序密钥（API Key）。图片和视频分别检查。 |
| 使用已有素材 | 告诉助手文件位置，只生成缺少的部分。 |

插件目前能直接连接 **OpenAI 图片生成**和**火山方舟 Seedance 视频生成**；其他服务先确认能否接入。模型就是具体负责生图或生成视频的工具，效果、速度和费用各有不同，让助手按你的需求和账号权限推荐。

## 把这段话发给助手

替换【】里的内容；还没选好服务就写“未确定”：

> 请帮我配置 wukong-drama。我用【软件名称】，图片用【方式】，视频用【服务】，计划做【时长、横竖屏】，预算【金额和币种】。请说明还缺什么、可用模型和预计费用，指导我填写设置。只配置，不生成。

密钥相当于给程序用的密码。按指导在**实际运行制作工具的环境**填写，别把完整密钥发进聊天或写进作品、公开文件；检查只报告“已设置／未设置”。换软件或电脑后要重新确认。

助手请读[配置操作参考](providers-reference.md)。本地检查通过，只说明设置能读到；账号权限和额度仍要到服务平台核对。真实生成测试也可能收费，须先确认。

当前源码的新片默认保留模型原生声音（0.1.0 发布包仍默认关闭）。想自己配音或配乐，可以告诉助手关闭；没有对白也可以保留环境声和音效。

## 费用怎么确认

- **每批图片**：弹窗说明要生成什么、数量和已知费用，选择可用方式并确认生成；助手自带工具无法估价时，会说明费用／额度由平台管理。
- **每批视频**：弹窗列出模型、数量、每条时长、预计费用和预算，等你明确确认“开始生成”。重试、返修和另做横竖屏都要重新确认。没有弹窗时改用文字询问并等待答复。
- **素材可能比成片长**：例如生成较长素材再剪成 10 秒，开始前会说明原因和费用。不同币种分开说明，预算用于提交前检查，实际费用以服务商账单为准。
- **失败先暂停**：保留成功素材，换方式或重生成由你决定。排队久了先查原任务，显示成功却没文件时先找回结果，避免重复提交。

提示密钥缺失、模型无权限或额度不足时，让助手检查设置，并到服务平台核对；不要猜型号或费用。

准备好后，回到[开始制作](../README.md#开始制作)，把故事告诉助手。
